v0.9 asset catalog + screenshot-inspired Send interface. It is suitable for
updating a v0.7 or v0.8 source tree (NOT for installing over a live funds wallet).

IMPORTANT: This ZIP contains SOURCE FILES, NOT AN APK.
DO NOT upload the ZIP as a single file.
DO NOT erase your existing repository or its history.

CONTENTS of the extracted patch folder onto GitHub. Ensure paths are at the
repository root: e.g. lib/main.dart (not v09_patch/lib/main.dart).

click pencil, paste replacement contents, and Commit. Create any NEW files
with Add file > Create new file using their complete relative paths.

FEATURE LIMITS:
- No real signing or broadcast. Review-screen only.
- BTC/LTC low/standard/high are FEERATE-based planning estimates for illustrative
  transaction sizes; exact UTXO fees are not calculated.
- EVM standard gas-price estimate is approximate; L2 posting fees and token
  execution amounts are not known. TRON Energy/Bandwidth not estimated.
- TRC-20 is a TRON (T...) address, separate from Ethereum.
- ETH, BNB, USDC, USDT and other EVM address-preview networks may share an EVM
  account address; their balances, tokens, and fees are NOT pooled.
- Only the seven ChainAsset balances are indexed. Other displayed entries
  are address previews, NOT send-ready wallets or balances.
- TON / GRAM, SFP BEP20, MAG7.ssi and other exotic tokens NOT added without
  verifying the chain-specific key derivation or authentic token contract.
- This prototype is NOT independently security audited. Do not fund with real coins.
