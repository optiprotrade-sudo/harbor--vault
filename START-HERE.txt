HARBOR VAULT v1.4 — ONE CLEAN GITHUB UPDATE

This ZIP is the complete source project, NOT an APK. Its files are at ZIP ROOT.
It includes all prior v1.3 features; DO NOT upload earlier patch ZIPs too.

HOW TO UPDATE YOUR EXISTING PRIVATE REPOSITORY ON WINDOWS
1. Keep an offline written backup of any existing test-wallet recovery phrase.
   Do not uninstall the previous APK without validating recovery.
2. Extract this ZIP to a regular folder (not to the GitHub upload field).
3. With Git for Windows installed, double-click PUSH-TO-GITHUB.bat.
4. Type APPLY to clone optiprotrade-sudo/harbor--vault into a temporary directory.
5. Review the Git status, then type PUSH to commit one consolidated update.
6. On GitHub: Actions > Build Harbor Vault Android APK > Run workflow > main.
7. If successful, download the Artifacts ZIP and extract app-release.apk.

NO GIT FOR WINDOWS?
Upload the CONTENTS (not the outer folder) of the following paths to the
corresponding GitHub repository paths: lib/, test/, scripts/, .github/workflows/,
pubspec.yaml, and analysis_options.yaml. Keep .github as a dot-folder.
GitHub web UI cannot replace all existing files safely with a single folder
upload in every case; prefer the Git script or GitHub Desktop.

WHAT v1.4 CHANGES
- New full-screen locked state: Welcome back, fingerprint icon and manual retry.
- One automatic Android identity request per launch or genuine background return.
- No double request after Android's fingerprint window resumes the activity;
  OS sticky automatic retry is disabled.
- Cancelling or failing remains locked and does not prompt automatically again
  until a real background/return or a deliberate tap on Unlock.
- Security options grouped: Unlock, Backup, Privacy, Advanced.
- Owner grouped: Wallet Profile, Networks, Testing, About.
- 1/2/3 minute inactivity timeout; background locks immediately.
- v1.2 notification bell, read/unread history and owner checklist preserved.

TEST ON YOUR PHONE (test wallet, not real funds)
A. Launch an existing wallet: Welcome back remains behind ONE Android prompt.
B. Cancel biometric prompt: still locked, no new automatic prompt; tap Unlock.
C. Try successful fingerprint, failed fingerprint and device PIN fallback.
D. Switch to another app and back: lock and ONE prompt again.
E. Wait 1/2/3 minutes inactive while wallet open: it locks.
F. Navigate Security and Owner expansion cards, verify settings persisted.
G. Notification bell still functions and doesn't reveal wallet while locked.
H. Send review still needs a FRESH authentication; NO FUNDS are sent.

LIMITATIONS
The app has not been built with Flutter in this environment; GitHub must run
its Dart tests and Android compilation. A clean ZIP is NOT proof that the code
compiles or has been security audited. Mainnet transfers remain disabled.
Not all address previews are balance-indexed or independently validated.
Do not hold or deposit real cryptocurrency in this prototype.
Use a stable Android signing key for future updates; changing signatures may
prevent installation over the previous APK. Backups and restoration tests first.
